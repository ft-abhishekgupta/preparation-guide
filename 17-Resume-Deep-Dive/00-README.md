# 17. Resume Deep-Dive

A resume deep-dive round is a guaranteed round at Technical Lead level. Every bullet must survive 5 minutes of follow-up questions: problem, constraints, alternatives, architecture, trade-offs, metrics, and what you'd do differently.

| # | Note | Priority | What it covers |
| - | ---- | -------- | -------------- |
| 01 | [Project Case Studies](01-Project-Case-Studies.md) | P0 | Full case study for each of the 9 resume items: elevator pitch, architecture diagram, key decisions table, hard problems, metrics, what I'd change, 8-12 deep-dive Q&A per project |
| 02 | [Resume Bullet Drilldown Checklist](02-Resume-Bullet-Drilldown-Checklist.md) | P0 | Checklist per bullet, interrogation question bank, "what was YOUR contribution" technique, estimation when you lack exact numbers, scoring rubric, 20-question rapid-fire self-quiz |

**How to use this folder:**

1. Work through every case study in `01` — not just the ones you feel confident about. Interviewers probe the stories that sound too polished.
2. For each case study, speak the elevator pitch aloud before reading the deep-dive section. Time it.
3. Use the checklist in `02` to self-audit: any row without all five checkboxes is a gap to close before the interview.
4. Run the 20-question rapid-fire self-quiz at the end of `02` as a final readiness check.
5. Cross-link: each case study references the matching system design in `../06-System-Design-Case-Studies/` for deeper architectural context.

**Time to revise:** ~120 minutes first read; ~30 minutes rapid-fire quiz on interview morning.
