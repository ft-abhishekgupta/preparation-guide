# 14. Frontend — React

> Covers enough React, TypeScript, state management, performance, and web fundamentals for a **backend-specialist** to answer frontend questions confidently without pretending to be a frontend expert. P2 overall — interviewers probe this to check breadth, not depth.

**Honest scope note:** You are a senior backend engineer. The goal is to speak competently about React architecture, data flow, common performance traps, and the web platform — not to compete with a dedicated frontend specialist. Lead with "I've shipped React in production as part of a full-stack system; here's what I care about…"
